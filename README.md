# DataProject-Python-Katas

Resolución completa y documentada de 41 katas en Python. El objetivo del proyecto es consolidar bases de desarrollo mediante la resolución de ejercicios sobre algoritmos, programación funcional, control de excepciones y Programación Orientada a Objetos (POO) como visto en clase.

---

# Estructura del Repositorio

* **`Ejercicios/`**: Carpeta que contiene los archivos Python `.py` con el código resuelto de los ejercicios
* **`Diario de Aprendizaje_ Katas de Python.pdf`**: Documento detallado donde se analizan las principales dificultades que he encontrado realizando los ejercicios.
* **`EnunciadoDataProjectPython.pdf`**: Documento con los requerimientos y enunciados originales del proyecto.
* **`README.md`**: Guía y presentación general del repositorio.

---


## Tecnologías Utilizadas

* **Lenguaje:** Python 3.14.3
* **Librerías Nativas:** `functools` (`reduce`), `math`
